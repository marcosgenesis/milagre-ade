# Milagre help

Answer the question using the relevant shipped reference:

- [Desktop, Chats and Accounts](references/desktop.md)
- [Host ownership and troubleshooting](references/host.md)
- [Phone pairing and connectivity](references/phone.md)
- [Advisors and committee](../milagre/references/advisors.md)

Identify which desktop, computer host or phone is affected. Use the owning Project/Named Link Account and that host's reported model/status data. Ask one focused clarification only when the affected computer or operation is unclear.

Start with narrow read-only diagnosis. A packaged app does not require a development checkout, npm, a Cloudflare account or a separate Node installation. Never invent Paseo commands or assume launch profiles/schedules exist. Separate observed errors from hypotheses.

Keep credentials, pairing links, QR contents and raw credential files out of replies and diagnostic output. Report status and redacted errors. Change settings, reset access or stop a host only within the user's authorized request. A host restart stops active work, including this diagnosing Chat; make its impact explicit before requesting one. Preserve transcripts and ownership locks unless a confirmed recovery requires a specific change.
